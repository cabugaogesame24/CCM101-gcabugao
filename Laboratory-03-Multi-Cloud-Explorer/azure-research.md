# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides services for computing, storage, databases, networking, security, analytics, and application development. Azure is widely used by organizations that already use Microsoft technologies.

## Global Infrastructure

Azure operates a worldwide cloud infrastructure with Regions and Availability Zones. Organizations can deploy their applications in different geographic locations to improve availability, performance, and reliability.

## Cloud Management Console

The Azure portal is a web-based interface used to manage Azure resources. Users can create virtual machines, configure storage, manage databases, monitor services, and control access through the portal.

## Four Core Services

1. *Azure Virtual Machines* – Provides virtual servers for running applications and operating systems.
2. *Azure Blob Storage* – Provides object storage for files and unstructured data.
3. *Azure SQL Database* – Provides a managed relational database service.
4. *Azure Virtual Network* – Provides private networking for Azure resources.

## Three Advantages

1. Azure integrates well with Microsoft products and services.
2. Azure provides a wide selection of cloud services.
3. Azure supports organizations with global cloud infrastructure.

## Typical Enterprise Use Cases

Enterprises use Azure for migrating Windows Server workloads, hosting business applications, managing databases, integrating Microsoft 365 environments, creating virtual networks, and supporting hybrid cloud environments.
