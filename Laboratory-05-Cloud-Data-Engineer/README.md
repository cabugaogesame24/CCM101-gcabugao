# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory focused on cloud object storage and the use of MinIO. I used Docker to run a MinIO server and accessed its Web Console through a forwarded port. I also created a bucket and uploaded a sample file to test the storage system.

## Objectives

- Learn the differences between Block, File, and Object Storage.
- Set up MinIO using Docker.
- Access MinIO through a web browser.
- Create and use an object storage bucket.
- Upload a file to the created bucket.
- Practice documenting cloud activities using Markdown.

## Tools Used

- KillerCoda Playground
- Ubuntu
- Docker
- MinIO
- GitHub
- Web Browser
- Markdown

## Skills Learned

- Basic cloud storage concepts
- Docker container deployment
- Using environment variables
- Working with ports and port forwarding
- Creating storage buckets
- Uploading objects to MinIO
- Writing technical documentation in Markdown
