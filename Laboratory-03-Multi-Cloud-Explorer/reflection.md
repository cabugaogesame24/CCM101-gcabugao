# Mission Reflection

The cloud platform that impressed me the most is Google Cloud Platform. I found its Artificial Intelligence, Machine Learning, and Kubernetes capabilities interesting. It showed me how cloud platforms can support newer technologies and not only basic server hosting.


AWS, Azure, and GCP all provide important cloud services such as computing, storage, databases, networking, security, and identity management. They also have global infrastructure that allows users to deploy applications in different locations. All three platforms can help organizations reduce the need to maintain physical infrastructure.

Business requirements are important because each organization has different needs. Factors such as budget, existing technology, performance, security, scalability, and future growth can affect the decision. For example, Azure is a good choice for an organization that already depends on Microsoft technologies, while GCP can be useful for AI and Machine Learning projects.


I learned that choosing a cloud provider should be based on the client's actual problem and requirements. There is no single provider that is always the best for every organization. I learned to compare services and consider how they can solve a client's technical and business needs.


My GitHub Cloud Computing Portfolio became more organized after completing this mission. I added research about AWS, Azure, and GCP, service comparison tables, client recommendations, a decision matrix, and my Linux investigation. I also practiced using Markdown and organizing screenshots as evidence. This activity helped me improve both my cloud computing knowledge and my technical documentation skills.
