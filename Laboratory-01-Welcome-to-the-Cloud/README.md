# Laboratory 01 – Welcome to the Cloud
## Mission Overview
This lab introduced me to the Linux environment and the basic tasks every cloud engineer should know. I used KillerCoda to work with Linux commands and GitHub to build my very own Cloud Computing portfolio.

## Objectives
- Access a Linux environment using KillerCoda
- Explore and navigate through Linux
- Gather and check basic system details
- Create and organize files and folders
- Set up a GitHub repository
- Document outputs using Markdown format

## Activities Performed
- Accessed Ubuntu through KillerCoda
- Created and logged into my own user account
- Checked my username, working directory, and system name
- Collected information about the Linux system
- Made folders and Markdown files for documentation
- Built and organized my Cloud Computing portfolio on GitHub

## Linux Commands Used
- whoami, pwd, hostname
- adduser, usermod, su
- cat, uname, lscpu, free, df
- mkdir, nano, touch, cp

## Skills Learned
I learned how to use basic Linux commands and manage files and folders. I also learned how to create users, check system information, and organize my work using GitHub. I became more familiar with using the Linux terminal and documenting my work.
