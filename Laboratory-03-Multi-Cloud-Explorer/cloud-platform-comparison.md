## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest selections of cloud services among the three providers. It has services covering computing, storage, networking, databases, security, analytics, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the best choice for Microsoft technology integration. It works closely with Windows Server, Microsoft 365, Active Directory, and other Microsoft products.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong provider for Artificial Intelligence and Kubernetes. It offers AI and Machine Learning services and Google Kubernetes Engine (GKE) for managing containerized applications.

### 4. Which cloud platform would you personally choose and why?

I would choose AWS because it has many different services that can support various types of applications. I also think its wide service selection would give me more opportunities to learn and work with different cloud technologies.
