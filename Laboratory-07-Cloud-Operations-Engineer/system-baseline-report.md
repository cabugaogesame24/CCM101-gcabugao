## Host Resource Values

- **Total Storage capacity of root (`/`) file system:** 19G

## Why Check Disk Space Before a Traffic Surge?
Checking available disk space before traffic increases is important because growing visitor numbers create more logs and temporary data. If storage runs full, the server cannot write new files, services stop, and the system may become unresponsive entirely.
